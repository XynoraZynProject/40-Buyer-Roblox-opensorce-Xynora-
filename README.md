IMPORTANT (Please Read Carefully)!!!

Item Buyer will ONLY work if you publish your game to a group that IS NOT owned by you (Buyer).
Therefore, you must use an alt acc. to create a group, and then publish your game with the Item Buyer to that group.

--

AUTO-SETUP:
1) Publish your game and then go to game settings and enable "Allow Third Party".
ไปที่ File > Publish หรือ Publish As (หากมีตัวแมพเปล่าที่เคยสร้างไว้แล้ว) ให้ Publish แมพนี้ แล้วไปที่ File > Experience Setting > Security > Allow Third Party Sales ให้เป็น 'Enable' (สีเขียว)

--

MANUAL-SETUP (DISABLE 'AutoSetup' Script Before Following):
ให้ Disable ตัว AutoSetup หรือ ลบออกไปเลย แล้วทำตามด้านล่างนี้

1) Move the "CatalogBuyer" into the StarterGui.
ย้าย CatalogBuyer (ไอคอนสี่เหลี่ยมโปร่งสีน้ำเงิน) ไปไว้ใน StarterGui

2) Publish your game and then go to game settings and enable "Allow Third Party".
ไปที่ File > Publish หรือ Publish As (หากมีตัวแมพเปล่าที่เคยสร้างไว้แล้ว) ให้ Publish แมพนี้ แล้วไปที่ File > Experience Setting > Security > Allow Third Party Sales ให้เป็น 'Enable' (สีเขียว)

--

Switch to your main account, join your game and buying an item by using In-Game 'Item Buyer'. 
You will get 40% comm after 2 - 4 weeks (or about 1 month) after buying.
สลับกลับมาที่รหัสหลัก ซื้อผ่านเกมนี้้เท่านั้น และ 40% comm จะเข้าประมาณ 2-4 สัปดาห์ หรืออาจจะประมาณ 1 เดือน หลังกดซื้่อไอเทมนั้น ๆ

If it doesn't work, try checking if you've done every steps correctly.
หากมันติด หรือทำไม่ได้ ให้คุณเช็คขั้นตอนการทำอย่างละเอียด ให้ถูกต้องหมดก่อน
